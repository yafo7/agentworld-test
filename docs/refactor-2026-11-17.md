# Chii Island 重构升级 · 2026-11-17

本次在 `agentworld-test` 的现有工作区上增量修改。开始时分支为 `codex/worldforge-integration`、HEAD 为 `4d77497`，已有居民 Agent、提示词编译与 WorldForge 多世界等未提交开发成果。本次保留这些成果，没有将整个工作区差异作为本次新增功能。

## 设计与兼容边界

保留田园创造、森林召唤、城镇活动与建造、序章和岛屿故事推进。居民身份、数值、地图布局、模型、动画、天气规则、渲染器和物理更新顺序均沿用现有实现。存档键、版本、场景隔离、Auto/Record 和生成资产引用格式不变。

本次没有更新 Three.js、Rapier、Studio 或 WorldForge 依赖，没有重新生成或同步任何游戏资产。

## 已实施的改动

| 层面 | 改动 | 对应行为 |
| --- | --- | --- |
| 代码组织 | 新增 `gameplay/createChiiAnimalAgents.js`，从 `main.js` 提取居民认知系统组装 | 对象创建即加入应用生命周期，启动中途失败也可清理；保留每帧调用顺序 |
| 居民异步状态 | 决策互斥、生命周期代次、返回后的宠物状态复查 | 慢请求不重入；旧决策、动作完成与反思不写入恢复后的会话；思考失败继续确定性选择 |
| 推理约束 | 校验候选动作与目标的完整组合 | 后端返回未提供的目标时保留原有确定性候选；无目标的 `null`/`undefined` 等价 |
| 居民持久化 | `AnimalAgentStore.saveMany` 与一次快照捕获 | 每轮保存合并为一次读取、一次写入；保留当前未加载居民的已有记录 |
| 清理 | 存档失败时仍释放居民控制标记；清理世界会话与调试引用 | 存储异常不会阻断其余资源释放，错误继续向生命周期调用者报告 |
| 世界切换 | 加载互斥、面板关闭取消、错误反馈与重试 | 多次点击只准备一次切换；先成功保存再确认目的地；过期请求不能覆盖新目录 |
| 界面安全与维护 | 世界目录使用文本节点、委托点击事件 | 名称、描述、错误消息不解释成 HTML；刷新列表不累积逐项监听器 |
| 背包 | 稳定物品 DOM、原位更新选择/装备状态 | 选择物品保留缩略图、键盘焦点，忙碌状态仍由 InventorySystem 管理 |
| HUD | 相同文本与活动投影跳过重复写入 | 每帧仍由原系统提供状态，减少无变化的 DOM 更新 |
| 输入 | 共用 `ModalFocusController`；对话输入支持 IME 确认 | Tab 留在当前面板，关闭恢复可见焦点；中文输入法 Enter 不提前发送；移除关闭后仍可能触发的输入框延迟聚焦 |
| 页面切换 | 跟踪并清理延迟导航计时器 | 重复导航只保留最后一次，dispose 后不再触发旧导航 |
| 界面呈现 | 内联样式移至 `island-shell.css`；`island-theme.css` 提供统一变量和视觉规则 | 奶油纸色、深绿重点、暖黄选择态；设置采用桌面双栏/窄屏单栏，固定标题与独立滚动区域 |

界面功能入口仍保留。对话、背包、世界选择、HUD 与物件编辑使用一致的边缘、字色和焦点样式，并加入安全边距和减少动态效果偏好支持。

## 复验命令

在项目目录启动游戏后执行：

```powershell
npm run verify
node .agents/skills/chii-verify/scripts/verify.mjs --full
node scripts/verify-ui-interactions.mjs
```

浏览器验证默认使用 `http://127.0.0.1:5173/src/demos/chii-island/?church-town`，可通过 `CHII_VERIFY_URL` 指向其他本地端口。

## 验证范围与剩余限制

本轮以已有本地资产和隔离浏览器会话验证，未对真实玩家浏览器存档做修改，也未新发起付费模型生成来覆盖全部在线 create/refine/mount 工作流。后端行为通过既有契约测试覆盖。

生产构建仍保留既有的大包警告；没有以变更冻结运行时依赖或拆改渲染循环的方式消除它。窄屏验证确认布局与键盘操作，不代表新增了移动端触屏操作方案。
