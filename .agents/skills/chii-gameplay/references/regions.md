# Region Gameplay Reference

## Windmill Pastoral

Purpose: pet-assisted home building and environment modification.

Current slice: follow/free roam, create object, refine object, mount part, construction presentation, persisted AI result.

## Temple Forest

Purpose: environment and companion wishes create or attract new pets.

Current slice: following pet + trophy questions + prompt synthesis + async pet generation + animations + introduction; tent camping and return to following.

## Church Town

Purpose: multi-pet public life, activities, animation, and VFX.

Current slice: town free roam, follow/free-roam dialogue, gather around campfire, group dance, party VFX, restore free roam.

These are regions of one island. Do not create separate engines, pet models, or persistence systems per region.
