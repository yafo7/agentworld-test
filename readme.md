# 宠物庭院师（AgentWorld）

3D 模拟养成 × 轻 RTS 经营类游戏，基于 Three.js + Vite。

> 玩家不是"抓宠物然后养"，而是"先创造一个值得生命到来的地方，然后观察什么样的生命愿意住进来"——进而派遣它们工作、战斗、社交，逐步开拓属于自己的奇异岛屿。

---

## 已实现功能（截至 2026-06-12）

### 核心玩法循环

```
玩家在 3×3 世界网格（9个单位环境）上漫游
  |
  ├─ E靠近宠物小屋 → 召唤宠物（马扣/扶摇/momo）在旁边一格生成
  |       └─ 再次E靠近小屋 → 宠物走回旁边一格 → 停顿 → 消失（可重新召唤）
  |
  ├─ 靠近宠物 → E抚摸 → 亲密度+1
  |       ├─ lv5: AI 生成新物品
  |       └─ lv10: AI 生成新环境 + 宠物寻主对话
  |
  ├─ 靠近装饰/建筑/树木 → E交互 → 播放呼吸动画
  |
  ├─ 靠近风铃 → E捡起 / 再次E放下
  |
  ├─ 进入外围环境 → 右上角提示 "按P展示/隐藏该地形内容"
  |       └─ 按O全局显示/隐藏所有外围环境（一键回到单中心场景）
  |
  └─ 屏幕底部实时显示 "xxx 按E互动/呼唤/召回/抚摸/捡起"
```

### 世界系统

| 系统 | 说明 |
|------|------|
| 世界网格 | 3×3 单位环境矩阵，间距 23。中心为玛扣大森林，周围 8 个差异化环境 |
| 单位面积 | 2×2×0.1 灰色体块，顶部齐平 Y=0，向下延伸不遮挡物体 |
| 单位环境 | 10×10 离散地块网格，单位面积之间留 0.05 缝隙。通过 `paintUnitArea()` 按类型染色 |
| 环境染色 | 树=浅绿 / 装饰=浅黄 / 宠物小屋=浅红 / 默认=灰色 |
| 环境实体 | 9 个环境各有一个中心主题模型（tree_marko/pond/grassland/forest/trainer/sun_stone 等） |
| 按需加载 | 外围 8 个环境默认隐藏物品；`O` 全局切换显隐，`P` 单环境切换显隐 |

### 实体系统

| 实体 | 种类 | 说明 |
|------|------|------|
| 玩家 | — | 蓝色圆锥，WASD 直接向量移动，forward = 摄像机观察方向 |
| 装饰品 | ps5游戏机 / ns2游戏机 / 雷霆大雪绒 | 不可移动，半尺寸，按 E 播放呼吸动画 |
| 树木 | 魔女 / yafo / 金鱼 / 星尘槐 | 不可移动，全尺寸，绿色单位面积 |
| 宠物小屋 | 马扣的家 / 扶摇的家 / momo的家 | 建筑类型，半尺寸，红色单位面积，映射专属宠物 |
| 田园商店 | — | 建筑类型（模型生成中） |
| 物品 | 风铃 | 唯一可捡起/放下的物品 |

### 宠物系统

| 宠物 | 家 | 描述 |
|------|-----|------|
| 马扣 | 马扣的家 | 热情小马驹，tag: 忠诚/奔跑/温暖/守护 |
| 扶摇 | 扶摇的家 | 洒脱小鸟，tag: 自由/风/高远/灵动 |
| momo | momo的家 | 圆滚小团子，tag: 慵懒/圆润/可爱/贪吃 |

- 宠物初始隐藏，E 靠近小屋 → 在**旁边一格**召唤出现 → 开始 wandering 走动
- 再次 E 靠近小屋 → 宠物走回**旁边一格** → 停顿 2s → 消失（可无限重复）
- 靠近已召唤宠物 → E 抚摸 → 亲密度 +1（0-10）
- 完整的亲密度/状态机/对话系统（继承原有宠物逻辑）
- 宠物动画差异：马扣（正常行走四肢摆动）、momo（正常行走）、扶摇（walk 为飞翔动作，翅膀大振幅扇动+身体上下浮动）

### 摄像机与操控

| 功能 | 方式 |
|------|------|
| 视角旋转 | 按住鼠标左键拖拽 |
| 缩放 | 滚轮 |
| 移动 | WASD（W = 摄像机观察方向，A/D = 左右平移） |
| 交互 | E 键（6 级优先级路由） |

### 交互优先级

| 按键 | 功能 |
|------|------|
| E | 6 级优先级：掉物 > 寻主对话 > 宠物抚摸 > 小屋召唤/召回 > 静态实体呼吸 > 捡起风铃 |
| P | 在当前外围环境内，切换该环境物品的显示/隐藏 |
| O | 全局切换所有外围环境的显示/隐藏（一键回到单中心场景） |

### 3D 模型与动画

- **Voxel Studio API** 生成全部模型（box/sphere/cylinder/cone/icosahedron 基本体）
- **Voxel Runtime** 播放动画（`swing`/`bounce`/`sway`/`breathe` 等）；不可用时自动 fallback 为客户端 sine wave 弹跳/呼吸
- 已预置 30+ 模型 JSON + 10+ 动画 JSON
- 已知限制：`tilt` 动画类型会导致 Voxel Runtime `evaluateMotion` 卡死，已禁用并改用 `swing` 替代
- `applyAnimation` 已添加 try-catch 防护，防止单只宠物动画异常导致全局崩溃

### 技术栈

- **Three.js** `^0.184.0` — 3D 渲染
- **Vite** `^8.0.12` — 开发与构建
- **DeepSeek API** — 文本侧 AI（宠物对话/里程碑物品/环境生成）
- **Voxel Studio API** — 3D 侧 AI（模型/动画/Runtime）

### 运行方式

```bash
npm install
npm run dev -- --host    # 开发模式
npm run build            # 生产构建
```
