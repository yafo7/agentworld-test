# Agentland Friends Art References

这个目录是 Agentland 朋友收集 Demo 的制作输入，不是浏览器运行时资产目录。

## 目录

- `scenes/`: 场景构图、平面图、材质和光照参考。
- `characters/`: 每位玩家的角色设定图，优先正面、侧面、背面或完整三视图。
- `references.json`: 稳定 id、文件、用途、来源和生成许可。

## 工作流

```text
组员放入参考图
→ 在 references.json 登记
→ Codex 阅读图片并整理结构、比例和可见特征
→ 通过 api-reference 后端生成场景或角色
→ 结果保存到 public/generated/agentland-friends/
→ 在 data/friendProfiles.js 或场景清单中登记
→ Demo 只读取已经落盘的运行时资产
```

浏览器页面上的文件选择器只做本次会话预览，不上传、不生成、不持久化。正式生成需要明确发起 Codex 任务，避免把参考图或密钥直接交给前端。

## 角色参考最低要求

1. 文件名使用稳定英文 id，例如 `yafo777-front.png`。
2. 至少提供一张全身正面图；有条件时补侧面和背面。
3. 写清身高比例、主要颜色、发型、服装和手持物。
4. 不确定的细节标为可自由设计，避免 AI 自行改掉身份特征。
5. 仅放入团队拥有使用权或明确允许用于生成的图片。

## 场景参考最低要求

1. 优先给俯视平面图或明确的空间分区图。
2. 标出角色活动区、障碍物、入口和主要故事焦点。
3. 给出大致尺寸或角色相对比例。
4. 区分必须还原的结构和仅供气氛参考的内容。
